# SAE S3 Développement d'une application

Projet universitaire de refonte de site web et de conception du système d'information de l'association ASFC : [Association Française du Syndrome de Fatigue Chronique (ASFC)](https://www.asso-sfc.org/)

L'Association Française du Syndrome de Fatigue Chronique (ASFC) accompagne les personnes malades ou en souffrance ainsi que leurs proches aidants pour rompre leur isolement, les informer et les orienter[cite: 2]. Elle s'appuie sur ses bénévoles pour organiser des ateliers, des groupes de parole, des permanences d'écoute et des événements.
